Persistent topology / simplified data-model cleanup
===================================================

Main changes
------------
1. FEM model is now explicit:
   - OptFEMModelStruct owns Nodes[] and Elements[].
   - Each OptElementStruct stores its C3D8 connectivity as 8 NodeIds.
   - The old OptNodeArrayStruct / OptElementArrayStruct wrapper types were removed.

2. Lattice model is now explicit:
   - OptLatticeModelStruct owns Tiles[] and persistent neighbour groups.
   - Each Tile owns its SubTiles[].
   - Each SubTile permanently stores:
       FirstElementIndex
       ElementIds[]
       ElementCount
     plus its thickness and current analysis values.
   - The old per-iteration OptElementStruct** pointer lists were removed.

3. INP topology is parsed only once per optimization run:
   - After the first real geometry export, before the first solver call.
   - ReadINP now reads node coordinates AND the 8 node IDs of each C3D8 element.
   - BindElementsToSubTiles establishes the permanent
     W -> V -> U -> SubTile -> FEM-element ownership once.
   - Later iterations do not re-read or re-bind the INP topology.

4. Solver results remain iteration-dependent:
   - SED and volume files are still read every iteration.
   - Master FEM elements are updated by permanent element ID.
   - Tile/SubTile aggregate quantities are recomputed from the persistent mapping.

5. Neighbour matching is split into two operations:
   - BuildNeighbourGroups(): geometric neighbour discovery, once per run.
   - ApplyNeighbourMatching(): averages thickness inside those stored groups after
     each design update. No geometric search is repeated.

6. remove_thin_tiles=true is rejected:
   - Removing geometry changes the FE topology and would invalidate the persistent
     element-to-subtile ownership. The new architecture therefore requires a fixed
     topology during one optimization run.

7. Multi-value U/V/W parsing remains unchanged from the previous single-body cleanup.
   Extra count sets are parsed/stored but only the first set is executed.
